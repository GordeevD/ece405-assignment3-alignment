In cases where the format reward is 0 (Category 3), the issue primarily 
lies with the base model’s output rather than the parser. 
As a small 0.5B model evaluated zero-shot, it frequently fails to follow the 
rigid system instructions. It often omits the required `<think>...</think>` 
tags for reasoning and the `<answer>...</answer>` tags for the final result, 
instead generating conversational, unformatted responses that the parser 
correctly rejects. 

In cases where the format reward is 1 but the answer reward is 0 (Category 2), 
the model accurately adopts the XML-like schema (the parser perfectly 
captures the content), but the extracted final answer is mathematically incorrect. 
This indicates the model struggled with the reasoning and arithmetic complexity 
of the MATH dataset despite adhering to the requested format.
